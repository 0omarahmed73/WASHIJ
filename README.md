# WASHIJ | وَشيج

Arabic-first digital art museum: brand design system and interactive prototype.

- `prototype/index.html`: open in a browser (needs internet for Google Fonts). Images are in `prototype/img`.
  Sources: `prototype/src` (data.js, style.css, app.js); `python3 prototype/build.py` rebuilds index.html.
- `design-system/project`: tokens.json, brand-book markdown and component previews.
- `design-system/assets`: logo SVGs.

Artwork images are public-domain files from Wikimedia Commons (credits are in each artwork page).
Published copies: prototype https://claude.ai/artifact/MQdFiBJhXB3STsQozethz9 · design system https://claude.ai/artifact/2siAkqCYvWpV8Evw2Qw8k2

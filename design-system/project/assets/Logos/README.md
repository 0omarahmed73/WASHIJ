Symbol files for WASHIJ. Each is the geometry only (frame plus thread), with no wordmark.

- `washij-symbol-gallery.svg`: ivory frame, star-yellow thread. For dark grounds.
- `washij-symbol-mono-ivory.svg` and `washij-symbol-mono-midnight.svg`: one ink, for foil, embossing and single-colour print. Ink is #F6F2E9 and #081B33.
- `washij-app-icon.svg`: midnight tile with the symbol at 74 percent and thicker strokes (5), corner radius 22.5 percent.

SVG loads through `<img>`, so colours are fixed in the files. The Arabic and English wordmarks are live type (Amiri Bold, Cormorant Garamond) and are not supplied as outlines.
